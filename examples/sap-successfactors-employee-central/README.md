## Illustration: Game PL108-046 Escape Room

- **Setup:** Five locked rooms; every room contains a Employee Central Core challenge based on the above topic scope.
- **Player action:** Inspect clues, make choices, enter codes, gather items and unlock the next room.
- **Scoring:** Start at 100, subtract configurable penalties for hints and incorrect attempts; preserve a separate win/lose outcome.
- **Win:** Clear all five rooms within a 20-minute configured session.
- **Replay:** Vary synthetic cases, clue order and seeded codes.
- **Safety:** No live SAP account or real customer records are required.

## Acceptance testing before publishing playable instances

1. Validate every mapped scenario against the official course and relevant product release.
2. Author actual playable content and solvable puzzles for each game; rows in this document are design briefs, not generated game assets.
3. Run the same universal game with two entirely unrelated content packs without engine changes.
4. Test win, loss, retry, timing, keyboard/touch, hint costs and results.
5. Do not claim platform completion, skills mastery or official certification based on an unverified game score.

**Mission:** Architecting experiences for a better world.
