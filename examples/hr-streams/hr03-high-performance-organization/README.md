**Edition:** Foundation / Silver example content pack · **Status:** 108 mapped designs; prototype runtime only · **Game IDs:** PL108-001–PL108-108

> The game templates are universal. This file changes **only the subject content**; no game mechanics are copied or modified.

## Learning purpose

Develop applied judgment about high performance organization through short, replayable 5–30-minute games. This is an Academy-created curriculum design, not a claim that all scenarios correspond to a specific official SAP course, implementation or certification.

## Four prototype assessment questions

1. **What should a measurable goal contain?** — Correct: **A clear outcome and metric**; distractors: Only a title / Only a color.

2. **What supports continuous improvement?** — Correct: **Regular actionable feedback**; distractors: Annual silence / Random ranking.

3. **What improves rating consistency?** — Correct: **Calibration**; distractors: Unreviewed assumptions / Hidden criteria.

4. **What should a performance discussion rely on?** — Correct: **Documented evidence**; distractors: Personal bias / Guesswork.
