**Edition:** Foundation / Silver example content pack · **Status:** 108 mapped designs; prototype runtime only · **Game IDs:** PL108-001–PL108-108

## Learning purpose

Develop applied judgment about rewards & performance through short, replayable 5–30-minute games. This is an Academy-created curriculum design, not a claim that all scenarios correspond to a specific official SAP course, implementation or certification.

## Four prototype assessment questions

1. **What prevents a compensation plan exceeding its limit?** — Correct: **Budget control**; distractors: Random draw / Tile grid.

2. **What is a pay range?** — Correct: **A defined compensation band**; distractors: A payroll date / An interview phase.

3. **What does pay equity analysis assess?** — Correct: **Fairness of compensation outcomes**; distractors: Website speed / Character count.

4. **What should occur before communicating approved rewards?** — Correct: **Authorization and validation**; distractors: Unreviewed posting / Random assignment.
