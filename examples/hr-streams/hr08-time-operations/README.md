**Edition:** Foundation / Silver example content pack · **Status:** 108 mapped designs; prototype runtime only · **Game IDs:** PL108-001–PL108-108

## Learning purpose

Develop applied judgment about time & operations through short, replayable 5–30-minute games. This is an Academy-created curriculum design, not a claim that all scenarios correspond to a specific official SAP course, implementation or certification.

## Four prototype assessment questions

1. **What stores an employee's accrued leave balance?** — Correct: **Time account**; distractors: Candidate pool / Agent tool.

2. **What defines expected working patterns?** — Correct: **Work schedule**; distractors: Salary statement / Interview question.

3. **What records work hours for a period?** — Correct: **Time sheet**; distractors: Succession chart / Requisition.

4. **What calculates payable or credited time from entries?** — Correct: **Time valuation**; distractors: Randomization / Career path.
