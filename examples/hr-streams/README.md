## Deployment and branding

- Comfortaa, bright blue/violet two-color gradient, second-line progress meter, sticky brand header and A/V/G/I footer.
- Local scores do not constitute verified certification. The 12 family prototype mechanisms still require full 108-game development.
- The existing Joule Studio example is retained as HR11's AI learning example, but Joule Studio is a cross-domain capability rather than an HR-only product.
- GitHub Pages must be configured separately, and a committed page is not proof of publication.
