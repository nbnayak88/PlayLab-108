# SuccessLabs PlayLab 108 — Digital Employee Experience (HR10)

**Edition:** Foundation / Silver example content pack · **Status:** 108 mapped designs; prototype runtime only · **Game IDs:** PL108-001–PL108-108

> The game templates are universal. This file changes **only the subject content**; no game mechanics are copied or modified.

## Learning purpose

Develop applied judgment about digital employee experience through short, replayable 5–30-minute games. This is an Academy-created curriculum design, not a claim that all scenarios correspond to a specific official SAP course, implementation or certification.

## Content scope

1. Employee journeys
2. Service delivery
3. Self-service
4. Knowledge content
5. Service cases
6. Digital adoption
7. Accessible experiences
8. Personalization
9. Experience metrics
10. Employee communications
11. Feedback loops
12. Cross-channel support

## Six-stage applied journey

1. Discover employee need
2. Map journey
3. Design touchpoints
4. Enable self-service
5. Capture feedback
6. Improve experience

## Four prototype assessment questions

1. **What describes linked moments across an employee's interaction?** — Correct: **Employee journey**; distractors: Payroll schema / Source code branch.

2. **What enables employees to complete routine actions directly?** — Correct: **Self-service**; distractors: Manual dependency / Hidden menu.

3. **What records a request through resolution?** — Correct: **Service case**; distractors: Pay period / Requisition.

4. **What makes experiences usable for diverse abilities?** — Correct: **Accessibility**; distractors: Only animation / Complex jargon.
