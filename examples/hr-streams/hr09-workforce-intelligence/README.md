# SuccessLabs PlayLab 108 — Workforce Intelligence (HR09)

**Edition:** Foundation / Silver example content pack · **Status:** 108 mapped designs; prototype runtime only · **Game IDs:** PL108-001–PL108-108

> The game templates are universal. This file changes **only the subject content**; no game mechanics are copied or modified.

## Learning purpose

Develop applied judgment about workforce intelligence through short, replayable 5–30-minute games. This is an Academy-created curriculum design, not a claim that all scenarios correspond to a specific official SAP course, implementation or certification.

## Four prototype assessment questions

1. **What measures the size of a workforce at a point in time?** — Correct: **Headcount**; distractors: Requisition ID / Wage type.

2. **What helps understand patterns of workforce exits?** — Correct: **Attrition analysis**; distractors: Color lab / Data deletion.

3. **What should be checked before using workforce metrics?** — Correct: **Data quality**; distractors: Animations / Guesswork.

4. **What groups insights by location or department?** — Correct: **Analytical dimensions**; distractors: Room keys / Clock-in event.
