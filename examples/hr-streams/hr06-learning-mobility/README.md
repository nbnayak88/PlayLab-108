# SuccessLabs PlayLab 108 — Learning & Mobility (HR06)

**Edition:** Foundation / Silver example content pack · **Status:** 108 mapped designs; prototype runtime only · **Game IDs:** PL108-001–PL108-108

> The game templates are universal. This file changes **only the subject content**; no game mechanics are copied or modified.

## Learning purpose

Develop applied judgment about learning & mobility through short, replayable 5–30-minute games. This is an Academy-created curriculum design, not a claim that all scenarios correspond to a specific official SAP course, implementation or certification.

3. Launch experience

## Content-pack vocabulary and clues

| Term | Learning clue |
|---|---|
| Learning item | Unit of learning content |
| Curriculum | Grouped learning structure |
| Assignment | Required or selected activity |
| Completion | Finished learning activity |
| Certification | Recognized qualification |
| Skill | Demonstrated capability |
| Learning path | Ordered development experiences |
| Compliance training | Mandatory policy education |
| Recommendation | Suggested learning experience |
| Mobility | Role or assignment movement |
| Opportunity | Possible growth experience |
| Learning record | Evidence of learning activity |

## Four prototype assessment questions

1. **What groups several learning activities?** — Correct: **Curriculum**; distractors: Payroll schema / Requisition.

2. **What confirms an activity was finished?** — Correct: **Completion record**; distractors: Job posting / Time clock.

3. **What supports a targeted development journey?** — Correct: **Learning path**; distractors: Random menu / Payment file.

4. **What connects people with internal career opportunities?** — Correct: **Talent mobility**; distractors: Payroll retro / Tax code.
