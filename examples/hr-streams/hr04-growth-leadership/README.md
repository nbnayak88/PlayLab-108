# SuccessLabs PlayLab 108 — Growth & Leadership (HR04)

**Edition:** Foundation / Silver example content pack · **Status:** 108 mapped designs; prototype runtime only · **Game IDs:** PL108-001–PL108-108

> The game templates are universal. This file changes **only the subject content**; no game mechanics are copied or modified.

## Learning purpose

Develop applied judgment about growth & leadership through short, replayable 5–30-minute games. This is an Academy-created curriculum design, not a claim that all scenarios correspond to a specific official SAP course, implementation or certification.

## Four prototype assessment questions

1. **What connects current role and future possibilities?** — Correct: **Career path**; distractors: Payroll area / Invoice.

2. **What is a successor readiness assessment intended to estimate?** — Correct: **Ability to assume a role**; distractors: Website clicks / Random points.

3. **What helps identify learning priorities?** — Correct: **Competency gap**; distractors: Color preference / Unverified labels.

4. **What is a mentoring relationship?** — Correct: **Guidance and learning support**; distractors: Automated payment / Time entry.
