# SuccessLabs PlayLab 108 — Talent Acquisition (HR02)

**Edition:** Foundation / Silver example content pack · **Status:** 108 mapped designs; prototype runtime only · **Game IDs:** PL108-001–PL108-108

> The game templates are universal. This file changes **only the subject content**; no game mechanics are copied or modified.

## Learning purpose

Develop applied judgment about talent acquisition through short, replayable 5–30-minute games. This is an Academy-created curriculum design, not a claim that all scenarios correspond to a specific official SAP course, implementation or certification.

## Six-stage applied journey

1. Define workforce need
2. Approve requisition
3. Attract applicants
4. Assess candidates
5. Extend offer
6. Transition to onboarding

## Four prototype assessment questions

1. **What begins a formally approved hiring request?** — Correct: **Job requisition**; distractors: Payroll run / Learning item.

2. **What tracks applicants through recruiting steps?** — Correct: **Candidate pipeline**; distractors: Posting document / Wage type.

3. **What is the purpose of a structured interview?** — Correct: **Consistent evidence gathering**; distractors: Random assignment / Uncontrolled scoring.

4. **What typically follows an accepted offer?** — Correct: **Onboarding transition**; distractors: Payroll closing / Succession nomination.
